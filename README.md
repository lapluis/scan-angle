# scan-angle

扫描图片偏角批量检测工具。根据纸张边缘、边框或其他长直线估算倾斜角度，输出 CSV 和红色标线预览。所有处理在本地进行，原图不会被修改。

## 功能

- 窗口界面与命令行两种入口。
- 支持 TIFF（含多页）、PNG、JPEG、BMP、WebP。
- 支持遍历子文件夹，损坏图片记录失败后继续处理。
- 每页输出偏差角、建议转正角、证据一致性状态和标线预览。
- 默认检测 ±15°，可调整到 ±30°。
- 先合并共线短线段，再按可配置的最短直线阈值筛选，因此虚线、断线中单独较短的片段也可能组成有效长线。
- 可配置分析图最长边和缩放算法；默认不放大原图。

## 开发运行

项目使用 uv 管理环境、依赖及锁文件，Python 版本固定为 3.14 系列（`.python-version` 和 `requires-python`）。先安装 uv。窗口界面需要 tkinter。

主要代码按职责拆分在 `src/scan_angle/`：

| 模块 | 职责 |
| --- | --- |
| `detection.py` | 设置校验、直线合并、长直线检测与偏角估算 |
| `batch.py` | 文件夹批处理、CSV/JSON/预览输出及字段常量 |
| `gui.py` | tkinter 窗口界面（tkinter 仅在此模块内导入） |
| `cli.py` | 命令行参数解析与 GUI／批处理调度 |
| `app.py` | 兼容旧导入的再导出层，不含实现 |

根目录 `main.py` 只保留入口导入和 `__main__` 调用，是统一运行和打包入口。`uv sync` 会将 src 包以可编辑方式安装到项目 `.venv`。

`uv.lock` 纳入版本控制；日常安装和 CI 使用 `--locked`，修改依赖后运行 `uv lock` 更新锁文件。

```powershell
uv python install 3.14
uv sync --locked
uv run --locked main.py
```

命令行批处理：

```powershell
uv run --locked main.py "D:\workspace\LACA-15637" --output ".\results\LACA-15637"
```

添加 `--recursive` 可包含子目录。统一使用根目录 `main.py` 入口。对超过 Pillow 默认像素保护上限的可信扫描图，可显式添加 `--allow-large-images`。

不带输入文件夹启动时，命令行中的设置（包括 `--recursive` 和 `--output`）会初始化窗口界面中的对应控件，而不会被丢弃：

```powershell
uv run --locked main.py --min-line-percent 25 --analysis-size 1600 --resample bilinear
```

## 检测设置

| 设置 | CLI | 默认 | 校验／说明 |
| --- | --- | --- | --- |
| 最大偏角 | `--max-angle` | `15` | 命令行和窗口为 1～30°；用于预筛线段并做最终范围检查 |
| 最短直线百分比 | `--min-line-percent` | `10` | 有限数值，范围 `(0, 100]`；相对分析图短边 |
| 最短直线绝对长度 | `--min-line-pixels` | `50` | 有限数值，必须大于 0；单位为分析图像素 |
| 分析图最长边 | `--analysis-size` | `2400` | 整数，范围 256～10000；只缩小，不放大原图 |
| 缩放算法 | `--resample` | `lanczos` | `lanczos` / `bicubic` / `bilinear` / `nearest` / `box` / `hamming` |

有效最短直线长度取两者较大值：

```text
max(min_line_pixels, min_line_percent / 100 × min(分析图高, 分析图宽))
```

默认 2400 像素分析图、短边 2400 时，阈值为 `max(50, 240) = 240` 分析像素。所有“像素”设置都指缩放后的分析图，不是原图像素；由于不放大原图，小图的分析图尺寸就是原图尺寸，阈值也会相应变小。设置在任何批处理开始前统一校验，NaN、无穷大、越界整数和未知缩放算法都会被拒绝。

## 结果说明

输出目录中包括：

| 文件 | 内容 |
| --- | --- |
| `angles.csv` | 每张图片、每页的检测结果，UTF-8 BOM，可用 Excel 打开 |
| `details.json` | 检测角度、合并后直线坐标、本次设置与合并诊断信息 |
| `previews/` | 标出参与估算的**合并后**直线的预览图 |

`angles.csv` 中“合并直线数”以及 `details.json` / 界面中的 `count` 都是**合并、筛选后参与角度共识的直线数量**，不是 OpenCV 原始线段数量。预览中的红线同样对应这些合并直线。

`details.json` 每条记录包含：

- `settings`：本次运行的最大偏角、最短直线百分比／像素、分析图最长边和缩放算法。
- `fragment_count`：排除图像边框和目标角度范围后，进入合并的原始线段数。
- `merged_count`：合并后的直线数（应用最短长度筛选之前）。
- `threshold_px`：本次分析图上的有效最短直线长度。
- `merge`：合并角度容差、垂直距离容差、间隙容差，以及原始、合并、入选数量。
- `lines`：入选的合并直线，含 `support_length`（去重后的实际支撑长度）、`span_length`（首尾跨度，包含未观测间隙）、`gap_length`、`member_count` 和方向。

读取失败的文件或页也会写入 `details.json`，并保留本次设置和错误说明。

**偏差角度正数表示顺时针倾斜，负数表示逆时针倾斜。** 建议转正角度采用同一符号约定，与偏差角度符号相反。例如偏差 `+1.724°`，表示建议逆时针旋转约 `1.724°`。

“可信”表示多条分离直线的方向较一致，是启发式判断，并非概率或测量精度保证。“需人工确认”可包含参考角度；角度空白表示没有足够证据。角度输出三位小数便于比较，并不意味着实际精度达到千分之一度。

每次运行会覆盖所选输出目录中的 CSV、JSON 和同名预览。建议不同批次使用独立输出目录。

## 直线合并

处理顺序是：EXIF 方向归一化 → 缩放为分析图 → OpenCV LSD 提取线段 → 排除贴近图像边框的线段和超出最大偏角的线段 → **合并共线片段** → 按有效最短长度筛选 → 角度共识。

合并规则：

- 水平方向和竖直方向分别处理。二者归一化后的偏角可能都是 0°，但绝不会互相合并。
- 端点顺序会先统一，因此反向输入的线段等价。
- 允许重叠和断开的片段；重叠部分只计一次，未观测的间隙不计入支撑长度。
- 合并容差（分析图像素，短边 = `min(高, 宽)`）：
  - 方向角差 ≤ `0.75°`；
  - 其他片段两个端点到锚定直线的垂直距离 ≤ `max(1.5, 0.0012 × 短边)`；
  - 相邻片段投影区间之间的间隙 ≤ `max(6, 0.005 × 短边)`。
- 默认 2400 像素短边时，垂直容差约 `2.88` 像素，间隙容差 `12` 像素。
- 每次取剩余片段中最长的一条作为稳定锚定直线，其他片段必须同时满足方向、角度和**两个端点**到该锚定直线的垂直距离条件；所有成员都直接对照最终锚定线复核，容差不会沿着链条逐段放大。
- 通过锚定检查的片段投影到锚定方向上，相邻投影区间间隙不超过容差即视为连通；与锚定片段处于同一连通分量的整条链一次成组，因此任意长度的共线断线都能恢复，且不受片段相对长度或输入顺序影响。
- 该组移除后再取剩余片段中的最长者作为下一组锚定线，结果确定且与输入顺序无关。逐个相邻片段都“勉强接近”的链条仍不会逐渐漂移成另一条线。

合并后的角度取各片段方向的去重加权平均，直线位置取支撑片段中点的去重加权位置；坐标跨度覆盖所有支撑片段。用于阈值和角度权重的 `support_length` 是投影区间的并集长度，因此：

- 重叠片段不会重复计权；
- 片段之间的大间隙不会被当作已观测证据；
- 单个片段都短于阈值时，只有合并后的实际支撑长度达到阈值才会入选。

超过间隙容差的两段不会合并，也不会为了凑长度而填满中间空白。

## 方法和限制

图片先按 EXIF 方向归一化，再按所选算法缩小为最长边不超过分析图设置的分析图（不放大）。使用 OpenCV 直线段检测器提取线段；排除图像边框后，按水平和竖直方向分别合并共线片段，再对合并直线应用最短长度和最大偏角筛选。最后按支撑长度加权寻找一致角度簇并计算加权中位数，结合空间上分离的直线数量、角度离散和竞争方向标记结果状态。

适合纸边、边框、表格线较清楚的扫描图。圆形光盘、无直线插画、浅色边缘、弯曲或透视变形可能无法可靠判断。画面内容中的设计斜线也可能影响结果，应核对预览。

合并是启发式处理：

- 间距小于垂直容差的两条平行边可能被视为同一条线（通常对应同一条粗线的两侧）；不同物理线条应保持更大的间距。
- 间隙大于容差或点间距过大的虚线不会被连接，可能因单段长度不足而不输出角度。
- 容差以分析图像素计，因此修改 `--analysis-size` 会同时改变可合并的间隙和垂直距离；需要跨批次严格一致时请固定该设置。
- 合并只依据几何关系，不判断语义；正文中的短横线、表格装饰线仍可能参与估算，请核对预览。

当前版本只检测偏角，不执行图像转正，不判断文字的 90°/180° 正反方向，也不做透视矫正，不自动旋转。

## Windows 打包

`uv sync --locked` 默认包含打包所需的 dev 依赖组，然后执行：

```powershell
.\scripts\build-windows.ps1
```

生成 `dist/ScanAngle.exe`，可在 Windows 64 位系统双击运行，无需单独安装 Python。EXE 是窗口程序，通过命令行启动时不显示终端进度，可查看结果文件。构建产物不纳入 Git。

GitHub Actions 使用 uv、锁文件及 Python 3.14，在 Windows 上执行测试和入口检查。
